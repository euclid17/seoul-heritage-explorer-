# 🏯 서울국가유산 탐사대 (Seoul Heritage Expedition)

> **서울 곳곳에 숨은 우리 유산을 찾아 떠나요!**  
> 초등학교 4학년 사회과 수업 및 창의적 체험활동을 위한 어린이 맞춤형 서울 국가유산 인터랙티브 웹 도감입니다.

---

## 🌟 주요 기능

1. **실시간 유산 검색 & 필터링**
   - 띄어쓰기 무시 검색 ("경복궁근정전" = "경복궁 근정전")
   - 이름, 한자명, 자치구, 시대, 상세 설명 통합 검색 (300ms 디바운스)
   - 종목별 필터 칩 (국보, 보물, 사적, 명승, 천연기념물, 무형유산, 민속유산, 등록유산, 서울시 지정)
   - 서울 25개 자치구 필터 및 사진 있는 유산만 보기 옵션
2. **오늘의 유산 도감**
   - 날짜를 기반으로 매일 새로운 서울의 대표 유산을 메인에 소개
3. **상세 정보 모달 & 사진 갤러리**
   - 고화질 대표 사진 및 추가 사진 갤러리 슬라이더
   - 종목, 시대, 소재지, 지정일, 관리자 핵심 정보 표
   - 어린이 눈높이 요약 설명 및 전체 내용 펼치기 토글
   - **📍 지도에서 보기**: 카카오맵 연동으로 위치 확인
   - **🔗 공식 출처**: 국가유산청 국가유산포털 공식 상세 페이지 새 탭 연동
4. **⭐ 내 탐사 수첩 (localStorage)**
   - 마음에 드는 유산을 수첩에 담고 언제든 다시 열람 (브라우저 로컬 저장)
   - '내 수첩에 담은 것만 보기' 필터 기능
5. **어린이 탐사 팁 & 저작권 준수**
   - 공공누리 제1유형(출처표시) 안내 및 학습 가이드 수록

---

## 🛠 기술 스택

- **Frontend**: Vanilla JavaScript (ES Modules), HTML5, CSS3
- **Build Tool**: Vite
- **Data Pipeline**: Node.js, `fast-xml-parser` (공개 API XML -> 정적 JSON 파이프라인)
- **Deployment**: Vercel

---

## 🚀 시작하기

### 1. 패키지 설치
```bash
npm install
```

### 2. 국가유산 데이터 빌드 (최초 1회 또는 갱신 시)
```bash
npm run build:data
```
> 국가유산청 공개 API에서 서울(11) 소재 전체 국가유산의 상세 정보와 이미지를 수집하여 `public/data/seoul-heritage.json`으로 정적 저장합니다.

### 3. 로컬 개발 서버 실행
```bash
npm run dev
```

### 4. 프로덕션 빌드
```bash
npm run build
```
